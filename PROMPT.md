# Product Prompt

Create **GeneralGroovy**, a practical guitar and music-theory practice application for players who want generated material that feels musical instead of random.

The app should generate:

- Picking patterns
- Riffs and motif cells
- Chords and progressions
- Arpeggios, legato, sweep picking, rhythm, reading, fretboard, songwriting, serial, post-tonal, microtonal-approximation, and mathematical prompts
- Ear-to-hands prompts
- Full mixed practice sessions

Practice material must be configurable by key, scale, theory system, transformation, tuning, capo, string set, fret range, position strategy, progression style, voicing type, rhythm feel, rhythm algorithm, meter, swing, rests, subdivision, Euclidean pulses, polymeter step, microtonal cent offset, tempo, tempo ramp, bar count, tone, technique constraints, density, randomization depth, goal, duration, and difficulty. Every randomizable parameter must be lockable. The generated output should include readable guitar tab, fretboard map, harmonic context, chord chart, analysis, tempo plan, playback, and creative variations that encourage musical use of the drill.

The first screen should be the tool itself, not a landing page. The interface should be compact, tactile, and musician-focused, with categorized controls on one side and tabbed generated practice material on the other. It should include browser-native audio playback with loop, waveform, volume, accent, rest, and step highlighting controls. It should run locally and on GitHub Pages as a static web app and remain easy to extend.
