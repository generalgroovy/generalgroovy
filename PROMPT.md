# Product Prompt

Create **GeneralGroovy**, a practical guitar practice application for players who want generated material that feels musical instead of random.

The app should generate:

- Picking patterns
- Riffs and motif cells
- Chords and progressions
- Ear-to-hands prompts
- Full mixed practice sessions

Practice material must be configurable by key, scale, string set, fret range, rhythm feel, tempo, bar count, technique constraints, and difficulty. The generated output should include readable guitar tab, a fretboard map, harmonic context, a tempo plan, and creative variations that encourage musical use of the drill.

The first screen should be the tool itself, not a landing page. The interface should be compact, tactile, and musician-focused, with controls on one side and generated practice material on the other. It should run locally as a static web app and remain easy to extend.
