# Product Prompt

Create **GeneralGroovy**, a practical guitar and music-theory practice application for players who want generated material that feels musical instead of random.

The app should generate:

- Picking patterns
- Riffs and motif cells
- Chords and progressions
- Arpeggios, legato, sweep picking, rhythm, reading, fretboard, and songwriting prompts
- Ear-to-hands prompts
- Full mixed practice sessions

Practice material must be configurable by key, scale, tuning, capo, string set, fret range, position strategy, progression style, voicing type, rhythm feel, meter, swing, rests, tempo, tempo ramp, bar count, tone, technique constraints, density, goal, duration, and difficulty. The generated output should include readable guitar tab, fretboard map, harmonic context, chord chart, analysis, tempo plan, and creative variations that encourage musical use of the drill.

The first screen should be the tool itself, not a landing page. The interface should be compact, tactile, and musician-focused, with categorized controls on one side and tabbed generated practice material on the other. It should run locally and on GitHub Pages as a static web app and remain easy to extend.
